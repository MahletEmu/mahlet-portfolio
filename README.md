# Mahlet Nigussie — Software Engineering Portfolio

> Personal portfolio showcasing full-stack web applications, AI integrations, and verified SheCodes frontend credentials.

**Live Website:** [https://mahlet-portfolio.vercel.app](https://mahlet-portfolio.vercel.app)

---

## 🚀 Overview

This portfolio is engineered using modern frontend and full-stack development practices with a dark theme aesthetic (deep navy `#040711`, electric violet accents, and restrained glow).

### Key Features
- **Featured Projects Showcase:** 6 real-world software engineering projects (Full-Stack & Frontend) with interactive architecture case studies and live demo links.
- **Verified Certifications Section:** Official SheCodes accredited credentials in Advanced Web Development, Artificial Intelligence, and Web Development with interactive full-resolution previews.
- **Interactive Experience:** Deep-linked project navigation with glowing pulse animations.
- **Direct Messaging Form:** Asynchronous in-page inquiry gateway delivering messages directly to Gmail with instant feedback.
- **Responsive Architecture:** Fully responsive across mobile, tablet, and widescreen viewports.

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, React Server Components)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Hosting:** [Vercel](https://vercel.com/)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/MahletEmu/mahlet-portfolio.git

# Navigate to project directory
cd mahlet-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
